# QRgen

**QR gen: A free QR generation project**

QRgen is a Streamlit application for generating customized QR codes from text, URLs, or CSV files. It supports custom colors, module styles, optional center logos, captions, and downloadable image files.

## Features

- **Single QR generation:** encode a URL or any text.
- **Batch generation from CSV:** create one QR code per valid row and download the results in a ZIP archive.
- **Custom appearance:** choose foreground and background colors, module shapes, image dimensions, and border size.
- **Optional logo:** place a PNG, JPG, JPEG, or WEBP image in the center of the QR code.
- **Optional caption:** add text below each generated QR code.
- **Error correction:** choose Low (L), Medium (M), Quartile (Q), or High (H). When a logo is supplied, QRgen automatically uses the highest error-correction level (H).
- **Export formats:** PNG, JPEG, and WEBP.
- **Local generation in the app session:** QR images are generated by the Python application; the project does not include a database or user-account system.

## Run locally

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_GITHUB_USERNAME/QRgen.git
cd QRgen
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
```

Linux / macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Start the application

```bash
streamlit run app.py
```

Streamlit will print a local URL (usually `http://localhost:8501`) that you can open in your browser.

## CSV batch format

Upload a `.csv` file with a header row. Each data row produces one QR code using the column selected in the app as the QR content. An optional second column can be selected for the caption printed below each QR code.

Example:

```csv
name,url
OpenAI,https://openai.com
Python,https://www.python.org
Streamlit,https://streamlit.io
```

In **Batch (CSV)** mode:

1. Upload the CSV file.
2. Select the column containing the QR content.
3. Optionally select a column to use as the caption.
4. Select **Generate batch**.
5. Download the ZIP archive containing the generated images.

Rows with empty content or generation errors are skipped and reported in the app. The ZIP contains the successfully generated QR codes.

## Customization notes

- **Error correction:** QRgen offers the four standard QR error-correction levels. Higher levels improve recovery from damage but can increase the density of the QR pattern.
- **Logos:** adding a logo automatically switches error correction to H. A logo can still make a QR code harder to scan.
- **Colors and styles:** strong contrast between foreground and background is recommended. Some decorative module styles and color combinations may not scan reliably.
- **Finder patterns:** you can keep the three corner finder patterns square while applying the selected style to the remaining modules.
- **Testing:** always scan exported QR codes with more than one device or QR reader before printing or sharing them.

## Privacy and responsible use

QRgen processes the text, URLs, CSV data, and optional logo files supplied by the user to generate QR images. The application code in this repository does not implement user accounts, a database, or persistent storage for generated QR codes. However, when hosted online, the app runs on the hosting provider's infrastructure; do not treat the service as a confidential or encrypted channel.

A QR code is **not encryption**. Anyone who obtains the QR image can scan it and read its encoded content. Do not encode passwords, payment details, identification numbers, health information, or other sensitive data.

Only upload logos and images that you own or are authorized to use. Do not generate QR codes for illegal, deceptive, malicious, harassing, or rights-infringing purposes.
